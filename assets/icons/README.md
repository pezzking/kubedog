# Kubedog icons

An orange square with round corners and a smiling dog, transparent outside. Raster exports, no vector original.

- `kubedog-16.png` … `kubedog-1024.png`: square PNGs. The app uses 32, 48, 64, 128 and 512 (`src/logo.rs`).
- `kubedog-macos.icns`: for the macOS app bundle.
- `kubedog-windows.ico`: for the Windows program (16 to 256 px).
- Linux: install the PNGs as `hicolor/{size}x{size}/apps/kubedog.png`.
